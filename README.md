# 🍄 Ramaz Truffe: Truffle Professional Website

A responsive showcase website for a truffle professional, presenting his services, training sessions and truffle sales, with a contact form for bookings and orders.

🔗 **Live:** [ramaztruffe.vercel.app](https://ramaztruffe.vercel.app)

<img width="1919" height="967" alt="image" src="https://github.com/user-attachments/assets/3a913a56-53db-41ae-9c23-cbdaee238f5a" />


## ✨ Features
- **Service pages:** truffle technician services, truffle-hunting training (fly method & dog training), truffle sales
- **Contact form** with a subject selector (training, dog training, truffle purchase, technician services, other)
- **Client reviews** section
- **Social links** (Facebook, Instagram, TikTok)
- **Fully responsive** design for mobile, tablet and desktop

## 🧰 Tech stack
- [Next.js](https://nextjs.org/) + TypeScript
- Deployed on [Vercel](https://vercel.com/)

## 🚀 Run locally
```bash
git clone https://github.com/abderrahmane-khoudour/ramaztruffe.git
cd ramaztruffe
npm install
npm run dev
```
Then open [http://localhost:3000](http://localhost:3000).
